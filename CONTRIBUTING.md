# Contributing

Thank you for your interest in contributing.

## How to Contribute

1. Fork the repository.
2. Create a feature branch:

```bash
git checkout -b feature/your-feature-name
```

3. Make your changes with clear commit messages.
4. Run available checks locally.
5. Open a pull request with a clear description of the problem and solution.

## Commit Style

Use short, clear commit messages, for example:

```txt
Add dashboard analytics cards
Fix mobile navigation layout
Improve API validation
```

## Pull Request Checklist

- [ ] Code is readable and organized.
- [ ] No secrets, API keys or production credentials are committed.
- [ ] README/docs are updated when needed.
- [ ] The app runs locally.
- [ ] Screenshots are attached for UI changes.

## Security

If you find a security issue, please do not open a public issue. Follow the instructions in `SECURITY.md`.
